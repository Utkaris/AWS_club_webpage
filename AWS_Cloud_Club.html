About the Club

The AWS Cloud Club at Ajay Kumar Garg Engineering College, Ghaziabad is a student driven technical community focused on Cloud Computing, DevOps, and modern cloud technologies.

The club aims to introduce students to cloud platforms such as Amazon Web Services (AWS) and help them develop practical skills through hands on learning sessions, workshops, and collaborative technical initiatives.

Through its activities, the club encourages students to explore modern cloud architecture, scalable application development, and industry relevant technologies.

Objectives

  • Promote learning of Cloud Computing and DevOps technologies
  • Provide hands-on exposure to AWS cloud infrastructure
  • Encourage students to build real-world cloud-based applications
  • Prepare students for AWS certification programs
  • Organize technical workshops, hackathons, and learning sessions
  • Create a collaborative community of cloud enthusiasts

Activities and Workshops

The AWS Cloud Club focuses on promoting learning and practical understanding of cloud computing and modern development technologies.

Key areas explored within the club include:

  • Introduction to Cloud Computing
  • Fundamentals of Amazon Web Services (EC2, S3, IAM)
  • Serverless Computing using AWS Lambda
  • Containerization using Docker
  • CI/CD pipelines and DevOps practices
  • Deploying scalable web applications on cloud infrastructure
